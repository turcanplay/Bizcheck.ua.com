referință — pentru „cum funcționează sistemul" mergi la [`../README.md`](../README.md).

## Regula de completare

Se scrie **după** verificare, nu înainte. O intrare din jurnal fără o comandă rulată și
o ieșire reală lângă ea e o promisiune, nu o consemnare. Ce n-a fost verificat se scrie
tot — dar marcat „neverificat", explicit.
