## Nota despre fotografii

Toate portretele din grila echipei sunt decupate circular pe fundal bleumarin închis
(`#0A2240`-ish), gata de folosit ca avatare rotunde. Excepție: `artem-vasylenko.jpeg`, luată de
pe slide-ul practicii IT fiindcă e vizibil mai mare (780×730 față de 516×483) — are fundal alb,
nu bleumarin, deci **nu se potrivește vizual cu celelalte**. Dacă vrei un set uniform, se
înlocuiește cu varianta din grilă.

Rezoluțiile diferă mult (252×277 … 1500×1500). Pentru un rând de avatare pe site, cele mici
(Папакін 300×300, Лащук 252×277) sunt limita de jos a ce se poate afișa decent la 2× pe retina.
